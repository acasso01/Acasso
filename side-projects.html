02 — LINUX & HOMELAB

Raspberry Pi Homelab · NAS, VPN, Home Assistant & RDP

Built a Raspberry Pi 4 home server. Formatted and mounted a 298 GB drive in fstab, shared it on the network with Samba, and reached it remotely without exposing it to the public internet. Joined the Pi and phone to a private Tailscale network, so the NAS and Home Assistant are reachable remotely, and ran Home Assistant in Docker for home automation. A HomePi monitoring view tracks processor, temperature, memory, and disk use. I later added RDP remote desktop, so I can open the Pi’s full desktop from my phone and work on it from anywhere on the private network.

Raspberry Pi 4 · Debian · Samba · Tailscale · Docker · Home Assistant · RDP
